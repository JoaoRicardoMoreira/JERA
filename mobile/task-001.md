# Task 001 - Bootstrap Expo

## Objetivo

Criar a aplicacao mobile em `apps/mobile` usando Expo, React Native e TypeScript.

## Contexto

A spec define React Native com Expo para manter TypeScript no monorepo e reaproveitar a API existente.

## Escopo

- [ ] Criar app Expo em `apps/mobile`.
- [ ] Configurar TypeScript.
- [ ] Configurar estrutura inicial `app/` e `src/`.
- [ ] Garantir que o app abra uma tela inicial simples.
- [ ] Adicionar scripts mobile no `package.json` raiz, se necessario.

## Arquivos ou modulos envolvidos

- `apps/mobile/**`
- `package.json`

## Criterios de aceite

- Projeto mobile inicia com Expo.
- TypeScript reconhece o app.
- Nenhuma alteracao funcional na API ou web.

## Dependencias

- Nenhuma.

## Observacoes tecnicas

Nao implementar telas finais nesta task.
