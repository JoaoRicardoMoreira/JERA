# Task 003 - Assets e Tema Jera

## Objetivo

Portar a identidade visual Jera para o app mobile.

## Contexto

O mobile deve manter deep dark, verde de marca, rose para gastos e violeta para investimentos.

## Escopo

- [ ] Copiar assets Jera de `apps/web/src/assets/brand`.
- [ ] Criar tokens de cor, spacing e tipografia.
- [ ] Criar tema base deep dark.
- [ ] Documentar uso de cores semanticas.

## Arquivos ou modulos envolvidos

- `apps/mobile/src/assets/brand/**`
- `apps/mobile/src/theme/colors.ts`
- `apps/mobile/src/theme/spacing.ts`
- `apps/mobile/src/theme/typography.ts`
- `apps/mobile/src/theme/components.ts`

## Criterios de aceite

- Logo Jera aparece no app.
- Tokens refletem `visual-identity-spec.md`.

## Dependencias
