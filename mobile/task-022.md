# Task 022 - Tela de Investimentos

## Objetivo

Implementar tela mobile de investimentos.

## Contexto

Equivale ao painel de investimentos do web, adaptado para tela dedicada.

## Escopo

- [ ] Cards: total aportado, patrimonio estimado, aporte do periodo.
- [ ] Edicao de taxa mensal.
- [ ] Equivalente anual.
- [ ] Grafico de evolucao patrimonial.
- [ ] Form de aporte mensal.
- [ ] Historico de aportes.
- [ ] Exclusao de aporte com confirmacao.
- [ ] Empty/loading/error states.

## Arquivos ou modulos envolvidos

- `apps/mobile/app/investments.tsx`
- `apps/mobile/src/features/investments/**`

## Criterios de aceite

- Dados batem com painel web.
- Taxa/aporte/delete funcionam.

## Dependencias

- Task 010.
- Task 021.

## Observacoes tecnicas

Grafico deve ser legivel em largura pequena.
